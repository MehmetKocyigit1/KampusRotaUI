# Isparta Gul Kremi Rota Planlama

Bu klasor, 20 satis noktasina gelen gunluk siparislere gore arac rotasi olusturan Java konsol uygulamasidir.

## Calistirma

```bash
cd GulKremiRotaPlanlama
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Uygulama siparis gelen nokta numaralarini ve arac sayisini sorar. Siparis listesi bos birakilirsa ornek bir gunluk siparis senaryosu calisir.

## Dosyalar

- `src/`: Java kaynak kodlari
- `PROJE_DOKUMANI.md`: proje dokumani
- `docs/graf_yapisi.mmd`: Mermaid graf cizimi
- `docs/graf_yapisi.dot`: Graphviz graf cizimi
- `docs/graf_yapisi.svg`: dogrudan acilabilir graf gorseli
